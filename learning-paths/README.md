# Learning Paths

第八阶段学习路线目录。

这个仓库已经有知识地图、示例、模板、案例、架构图、Runbook、决策指南和项目启动包。学习路线的作用是告诉你：不同背景的人应该先看什么、做什么、做到什么程度算过关。

## Paths

| Path | 用途 |
| --- | --- |
| [role-based.md](role-based.md) | 按角色选择学习路线 |
| [30-day-plan.md](30-day-plan.md) | 30 天完整软件学习计划 |
| [exercises.md](exercises.md) | 分模块实战练习 |
| [capstone-projects.md](capstone-projects.md) | 综合毕业项目 |
| [self-assessment.md](self-assessment.md) | 自评清单和能力刻度 |

## Recommended Start

如果你完全不知道从哪里开始：

1. 读 [modules/README.md](../modules/README.md)。
2. 跑 [examples/full-stack-mini-app](../examples/full-stack-mini-app/README.md)。
3. 按 [30-day-plan.md](30-day-plan.md) 走一遍。
4. 选一个 [capstone-projects.md](capstone-projects.md) 里的毕业项目。
5. 用 [self-assessment.md](self-assessment.md) 判断是否能独立启动真实项目。
