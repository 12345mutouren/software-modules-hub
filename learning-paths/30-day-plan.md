# 30 Day Plan

这是一个 30 天学习计划。每天的目标是小步完成，避免只收藏资料不真正理解。

## Week 1: Build The Map

| Day | Focus | Output |
| --- | --- | --- |
| 1 | 读模块总览和 README | 写出 10 大模块一句话解释 |
| 2 | 产品层、账号系统 | 写一个产品目标和用户角色表 |
| 3 | 数据库层、后端系统 | 画出用户/订单/日志数据关系 |
| 4 | 前端/客户端、安全 | 列出页面状态和权限风险 |
| 5 | 运维部署、测试 | 写发布和测试最小清单 |
| 6 | 商业/运营、文档 | 写支付、客服、FAQ 初稿 |
| 7 | 复盘 | 用 phase-1 checklist 自查 |

## Week 2: Run And Modify

| Day | Focus | Output |
| --- | --- | --- |
| 8 | 跑 full-stack-mini-app | 本地启动并截图或记录结果 |
| 9 | 读 API 和 store | 写 API 和数据表对应关系 |
| 10 | 读 security.js | 解释密码哈希、Cookie、CSRF |
| 11 | 读测试 | 解释 5 个测试覆盖什么风险 |
| 12 | 修改一个字段 | 给用户资料增加一个字段 |
| 13 | 增加一个 API | 增加一个只读 API |
| 14 | 复盘 | 跑 `npm test` 并记录结果 |

## Week 3: Choose A Template

| Day | Focus | Output |
| --- | --- | --- |
| 15 | 软件类型选择器 | 选择一个软件类型 |
| 16 | 读对应完整模板 | 写 10 模块组合表 |
| 17 | 读两个真实项目案例 | 写源码阅读入口清单 |
| 18 | 读架构图 | 画自己的参考架构 |
| 19 | 读运维 Runbook | 写部署和回滚计划 |
| 20 | 填项目启动模板 | 完成 product brief + module selection |
| 21 | 复盘 | 写 3 条 ADR |

## Week 4: Plan A Real Project

| Day | Focus | Output |
| --- | --- | --- |
| 22 | 权限矩阵 | 完成角色/权限表 |
| 23 | 数据模型 | 完成核心数据表 |
| 24 | API 合同 | 完成关键 API 草案 |
| 25 | 安全审查 | 完成 security review |
| 26 | 测试计划 | 完成 unit/API/E2E/permission 测试计划 |
| 27 | 发布计划 | 完成 launch plan |
| 28 | 风险登记 | 完成 risk register |
| 29 | 综合整理 | 形成项目启动包 |
| 30 | 自评 | 用 self-assessment 判断下一步 |
