# Capstone Projects

毕业项目用于把所有模块组合起来。每个项目都应该至少产出产品简报、模块选择、数据模型、API 合同、权限矩阵、测试计划和发布计划。

## Capstone 1: Mini SaaS

Build or design:

- 注册登录。
- 用户 Dashboard。
- 免费/Pro 计划。
- 订单或订阅模拟。
- 用量限制。
- 管理后台。

Must include:

- 支付 webhook 设计。
- 团队或角色权限。
- 发布和回滚计划。

## Capstone 2: Admin Dashboard

Build or design:

- 管理员登录。
- 用户列表。
- 用户详情。
- 审核队列。
- 操作日志。
- 导出任务。

Must include:

- 权限矩阵。
- 审计日志。
- 批量操作风险控制。

## Capstone 3: Ecommerce

Build or design:

- 商品列表。
- 商品详情。
- 购物车。
- 订单。
- 支付模拟。
- 后台订单管理。

Must include:

- 库存和支付幂等设计。
- 售后和退款流程。
- 订单权限测试。

## Capstone 4: Content Community

Build or design:

- 发布内容。
- 评论。
- 点赞/收藏。
- 举报。
- 审核后台。
- 搜索或标签。

Must include:

- XSS 防护。
- 举报和申诉流程。
- 推荐或排序策略。

## Capstone 5: AI Knowledge Base

Build or design:

- 文档上传。
- 文档分块。
- 向量检索。
- 问答。
- 引用展示。
- 答案反馈。

Must include:

- 文档权限过滤。
- 索引任务重试。
- 模型成本和质量评估。

## Capstone 6: Enterprise Internal Tool

Build or design:

- 员工登录。
- 提交工单。
- 审批流。
- 附件。
- 评论。
- 报表。

Must include:

- 部门权限。
- 审批审计日志。
- SLA 和通知策略。
