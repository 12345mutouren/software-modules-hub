# Self Assessment

用这个清单判断你是否已经从“知道有哪些模块”进阶到“能启动一个真实软件项目”。

## Level 1: Can Explain

- [ ] 能说出完整软件 10 大模块。
- [ ] 能解释登录、数据库、后端、前端、安全、部署、测试的关系。
- [ ] 能区分库、框架、模板、平台、真实产品源码和示例仓库。
- [ ] 能运行 full-stack-mini-app。

## Level 2: Can Design

- [ ] 能写 product brief。
- [ ] 能选择软件类型。
- [ ] 能写模块选择表。
- [ ] 能画数据模型。
- [ ] 能写 API 合同。
- [ ] 能写权限矩阵。

## Level 3: Can Build

- [ ] 能实现注册登录。
- [ ] 能实现一个核心业务 API。
- [ ] 能实现基础前端页面。
- [ ] 能写 API 测试。
- [ ] 能写权限测试。
- [ ] 能本地部署并运行。

## Level 4: Can Launch

- [ ] 能配置生产环境。
- [ ] 能写发布和回滚计划。
- [ ] 能配置日志、错误监控和健康检查。
- [ ] 能设计备份和恢复演练。
- [ ] 能写用户文档和管理员文档。

## Level 5: Can Operate

- [ ] 能处理事故。
- [ ] 能做安全审查。
- [ ] 能评估性能瓶颈。
- [ ] 能维护权限和审计日志。
- [ ] 能根据运营数据改进产品。

## Graduation Rule

如果你能完成：

- 一个 capstone 项目。
- 一个项目启动包。
- 一次 `npm test` 通过。
- 一份发布计划。
- 一份风险登记。

你就已经具备启动真实软件项目的基本能力。
