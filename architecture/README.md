## 使用方式

1. 先看 10 大模块关系图，理解完整软件的整体结构。
2. 再看请求流程图，把前端、后端、数据库、安全和通知串起来。
3. 根据目标产品选择 SaaS、电商或 AI 知识库参考架构。
4. 最后看运维生命周期，把代码发布、监控、备份和事故处理接上。
