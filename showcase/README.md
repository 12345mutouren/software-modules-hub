# Showcase

目标：让这个仓库不只“内容完整”，也能被快速理解、对外展示、按版本发布并持续维护。

## Files

| File | Purpose |
| --- | --- |
| [project-one-pager.md](project-one-pager.md) | 一页说明仓库是什么、给谁用、覆盖什么 |
| [repository-tour.md](repository-tour.md) | 按时间顺序带新读者浏览仓库 |
| [release-playbook.md](release-playbook.md) | 每次发布前后怎么检查、记录和推送 |
| [maintainer-handbook.md](maintainer-handbook.md) | 后续维护、扩展和审计原则 |
| [shareable-summary.md](shareable-summary.md) | 可复制到 GitHub 描述、项目介绍或分享文案 |

## When To Use

| Situation | Start Here |
| --- | --- |
| 想给别人解释这个仓库 | [project-one-pager.md](project-one-pager.md) |
| 第一次打开仓库，不知道读什么 | [repository-tour.md](repository-tour.md) |
| 准备发布一个版本 | [release-playbook.md](release-playbook.md) |
| 准备长期维护内容质量 | [maintainer-handbook.md](maintainer-handbook.md) |
| 需要一段项目简介 | [shareable-summary.md](shareable-summary.md) |

## Showcase Principles

- 先说明目标读者，再说明内容。
- 先给入口，再给细节。
- 不夸大成熟度：这是知识地图、模板、示例和审计体系，不是生产级 SaaS 成品。
- 展示材料必须和实际仓库内容同步。
- 每次发布都应该更新公开入口、质量验证说明、维护记录和 Changelog。
