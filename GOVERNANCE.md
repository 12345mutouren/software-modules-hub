# Governance

## Repository Purpose

Software Modules Hub is a learning, planning and reference repository for understanding complete software systems.

## Maintainer Responsibilities

- Keep the 10-module model coherent.
- Keep examples runnable.
- Keep verification scripts current.
- Avoid adding unverified or misleading production claims.
- Update README, Roadmap, Changelog, checklist and audit when adding a phase.

## Change Types

| Change | Review Requirement |
| --- | --- |
| Small wording fix | Run `npm test` when practical |
| New document | Update relevant index |
| New phase | Add checklist, audit, verifier coverage and changelog |
| New code example | Add tests |
| Security guidance | Review against security-compliance templates |

## Decision Record

Architecture or governance changes should use an ADR-style note before large restructuring.
