# Case Studies

第四阶段案例研究目录。

目标：拆解真实开源项目，观察完整软件的 10 个模块如何在真实仓库里组合。

## 真实项目拆解

| 项目 | 类型 | 入口 |
| --- | --- | --- |
| Cal DIY | 预约和日程 SaaS | [real-projects/cal-diy](real-projects/cal-diy/README.md) |
| Plane | 项目管理 | [real-projects/plane](real-projects/plane/README.md) |
| Twenty | CRM | [real-projects/twenty](real-projects/twenty/README.md) |
| Supabase | Postgres 开发平台 | [real-projects/supabase](real-projects/supabase/README.md) |
| Appwrite | 后端云平台 | [real-projects/appwrite](real-projects/appwrite/README.md) |
| Dub | 链接归因平台 | [real-projects/dub](real-projects/dub/README.md) |

## 阅读方式

1. 先读项目快照，确认项目类型和技术方向。
2. 再看 10 模块拆解，理解它如何覆盖完整软件能力。
3. 跟着源码阅读入口，从 README、apps/packages、docs、deploy/test 配置开始。
4. 最后看学习重点和风险，决定这个项目是否适合深入研究。
