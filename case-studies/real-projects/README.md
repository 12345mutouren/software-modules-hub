# Real Project Teardowns

这些案例基于 GitHub 当前仓库信息和顶层目录快照整理。

## 项目选择理由

| 项目 | 选择理由 |
| --- | --- |
| Cal DIY | 预约类 SaaS，适合学习账号、团队、日程、支付和全栈 TypeScript |
| Plane | 项目管理产品，适合学习任务、项目、协作、工作流和 Docker 部署 |
| Twenty | CRM 产品，适合学习对象建模、GraphQL、后台和业务数据关系 |
| Supabase | 基础设施平台，适合学习 Auth、Database、Storage、Realtime、Edge/API 组合 |
| Appwrite | 后端云平台，适合学习 Auth、Databases、Storage、Functions、Messaging、Hosting |
| Dub | 链接归因平台，适合学习短链接、分析、计费、团队和现代 Next.js SaaS |

## 统一拆解维度

每个项目都按这些维度拆解：

- Verified snapshot。
- 10-module map。
- Source reading entry points。
- What to learn。
- Risks and caveats。
- Suggested next exercise。
