# Product Spec

## 目标

这个示例软件用于演示一个完整 Web 软件的基础结构。它让学习者可以注册、登录、创建会员订单、提交反馈，并通过管理员账号查看用户。

## 用户类型

| 用户类型 | 说明 |
| --- | --- |
| 游客 | 可访问首页和查看登录状态 |
| 普通用户 | 可登录、创建订单、查看自己的订单、提交反馈 |
| 会员 | 创建 Pro 订单后获得 `pro` 计划 |
| 管理员 | 第一个注册用户自动成为管理员，可查看用户列表 |
| 运营 | 通过反馈数据和审计日志理解用户行为 |

## 核心功能

- 注册账号。
- 登录账号。
- 查看当前用户。
- 创建会员订单。
- 查看自己的订单。
- 提交反馈。
- 管理员查看用户。

## 使用流程

1. 用户打开首页。
2. 用户注册账号，第一个用户成为管理员。
3. 系统创建 Session 并返回 CSRF Token。
4. 用户创建会员订单。
5. 用户提交反馈。
6. 管理员查看用户列表。

## 页面/界面

- 首页。
- 注册表单。
- 登录表单。
- 会员订单表单。
- 反馈表单。
- 结果输出面板。
- 管理员用户列表入口。
