# Examples

第二阶段示例目录。

这里的目标不是把每个技术栈都实现一遍，而是先给 10 个软件模块提供一个能运行、能测试、能继续扩展的完整样例。

## 示例列表

| 示例 | 覆盖模块 | 说明 |
| --- | --- | --- |
| [full-stack-mini-app](full-stack-mini-app/README.md) | 10/10 | 一个无外部依赖的 Node.js 小型全栈软件示例 |

## 使用原则

- 示例要能本地运行。
- 示例要能被测试验证。
- 示例要明确映射到 10 个模块。
- 示例只做代表性实现，不追求生产级完整度。
- 生产系统应回到各模块文档和 GitHub 仓库索引继续选型。
