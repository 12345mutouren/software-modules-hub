# AI 知识库模板

适合：企业知识库、文档问答、客服知识助手、研发文档检索、个人资料库。

## 产品定位

AI 知识库的核心是把文档、网页、文件或数据库内容变成可检索、可引用、可追溯的问答系统。

典型目标：

- 上传或同步知识资料。
- 对资料分块、索引和向量化。
- 用户提问后检索相关内容并生成答案。
- 控制不同用户能访问哪些知识。

## 用户角色

| 角色 | 能力 |
| --- | --- |
| 游客 | 访问公开知识库或演示 |
| 普通用户 | 提问、查看可访问文档 |
| 编辑者 | 上传、编辑、删除文档 |
| 管理员 | 管理知识库、成员、权限 |
| 企业用户 | 团队知识库、SSO、审计 |
| 客服/运营 | 管理常见问题和反馈 |

## 10 模块组合

| 模块 | 设计重点 |
| --- | --- |
| 产品层 | 知识来源、问答场景、答案可信度 |
| 账号系统 | 团队、知识库权限、企业 SSO |
| 数据库层 | 文档、分块、向量、引用、会话、反馈 |
| 后端系统 | 上传、解析、索引、检索、生成、引用 |
| 前端/客户端 | 上传页、知识库管理、聊天界面、引用展示 |
| 安全 | 文档权限、数据隔离、提示词注入防护、审计 |
| 运维部署 | 向量数据库、对象存储、队列、模型服务、监控 |
| 测试 | 检索质量、权限、上传、引用、回归集 |
| 商业/运营 | 用量计费、会员、客服、反馈、质量分析 |
| 文档 | API、数据来源、权限说明、管理员手册、FAQ |

## 核心数据表

| 表 | 作用 |
| --- | --- |
| knowledge_bases | 知识库 |
| documents | 文档元数据 |
| document_chunks | 文档分块 |
| embeddings | 向量索引引用 |
| sources | 来源和同步状态 |
| conversations | 对话 |
| messages | 消息 |
| citations | 引用 |
| feedback | 答案反馈 |
| access_policies | 访问权限 |
| ingestion_jobs | 解析和索引任务 |
| audit_logs | 审计日志 |

## API 设计

| API | 说明 |
| --- | --- |
| `POST /api/knowledge-bases` | 创建知识库 |
| `POST /api/documents` | 上传文档 |
| `POST /api/documents/:id/index` | 触发索引 |
| `GET /api/documents` | 文档列表 |
| `POST /api/search` | 语义检索 |
| `POST /api/chat` | 提问 |
| `POST /api/messages/:id/feedback` | 答案反馈 |
| `GET /api/citations/:id` | 查看引用 |
| `GET /admin/api/ingestion-jobs` | 索引任务 |

## 页面设计

- 索引任务状态。
- 问答聊天页。

- 用量和账单。
- 管理后台。

## 关键检查

- [ ] 用户是否只能检索自己有权访问的文档。
- [ ] 答案是否展示引用来源。
- [ ] 上传文件是否限制类型和大小。
- [ ] 索引任务是否可重试。
- [ ] 是否有提示词注入和敏感信息防护。
- [ ] 是否有检索质量评估集。
- [ ] 是否记录模型用量和成本。
