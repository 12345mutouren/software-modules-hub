# v1.5.0 Release Notes

Date: 2026-06-04

## Summary

`v1.5.0` adds a Maturity Scorecard to the docs site.

The release gives project builders a live readiness tool for judging whether a software idea, prototype or starter package is ready to demo, launch or harden for production.

## Added

- `maturity.html` docs-site page.
- Interactive readiness score across the 10 core software modules.
- Module-level checklist cards for product, identity, data, API, UI, security, operations, testing, business and documentation.
- Live score, checked-item count, complete-module count and readiness level.
- Score bar with Map, Prototype, Launch Candidate and Production Ready levels.
- Next-action panel that highlights the lowest-scoring modules.

## Updated

- Home page now includes a Maturity Scorecard entry.
- Explore and Start Here now route project builders to the scorecard.
- Docs-site navigation now includes Scorecard.
- Docs-site tests now verify the generated scorecard page.
- Root version is now `1.5.0`.
- README, Project Status, Final Review, Changelog and Master Index now reflect the maturity scorecard release.
