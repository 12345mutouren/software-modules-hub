# v1.9.0 Code Foundation Release Notes

Date: 2026-06-14

## Summary

`v1.9.0` adds the first real code foundation to the hub.

The repository now includes reusable, tested code packages for core application primitives, security primitives and auth/RBAC, plus a management app that composes those packages into a working workflow.

## Added

- `packages/core`
  - `AppError`
  - assertion helper
  - ID factory
  - deterministic system clock
  - in-memory repository
  - audit log
- `packages/security`
  - password policy
  - scrypt password hashing
  - password verification
  - login rate limiting
  - HTML escaping
- `packages/auth`
  - registration
  - login
  - sessions
  - RBAC permission checks
  - auth audit events
- `apps/admin-code-foundation`
  - user registration
  - login/session flow
  - content creation and review
  - export jobs
  - audit log access
  - permission denial tests

## Updated

- Root version is now `1.9.0`.
- Root `npm test` now runs `test:code-foundation`.
- Repository verifier now requires the code foundation packages and admin app.
- README, Start Here, Master Index, Project Status, Final Review and Changelog now describe the code foundation release.
