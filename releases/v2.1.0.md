# v2.1.0 Real Web Admin App Release Notes

Date: 2026-06-14

## Summary

`v2.1.0` turns the data/API foundation into a browser-usable management app.

The release adds a dependency-light Node.js server and static admin UI that can log in, create content, review content, create export jobs and view audit logs through the API foundation.

## Added

- `apps/web-admin-app`
  - Node.js HTTP server
  - Static admin HTML
  - Static admin CSS
  - Static admin JavaScript
  - Demo admin and writer accounts
  - Browser workflow over `/api/*`
- Web admin tests
  - Static shell and asset serving
  - Admin login and workflow
  - Writer permission denial
- Root `test:web-admin` script.

## Updated

- Root version is now `2.1.0`.
- API public registration now always creates normal users.
- API package now includes:
  - `GET /me`
  - `GET /content`
  - `GET /exports`
- Root `npm test` now runs web admin tests.
- Repository verifier now requires the web admin app and v2.1.0 release notes.
- README, Start Here, Master Index, Project Status, Final Review and Changelog now describe the web admin release.
