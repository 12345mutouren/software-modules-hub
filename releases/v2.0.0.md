# v2.0.0 Data And API Foundation Release Notes

Date: 2026-06-14

## Summary

`v2.0.0` adds the first data and API foundation to the hub.

The repository now has model-specific repositories for core software objects and a framework-neutral API handler that composes data, auth and security packages into a complete backend flow.

## Added

- `packages/data`
  - User model
  - Session model
  - Role model
  - AuditLog model
  - Content model
  - ExportJob model
  - Repository contract
  - In-memory data store
  - Default RBAC role seeding
- `packages/api`
  - `GET /health`
  - `POST /auth/register`
  - `POST /auth/login`
  - `POST /content`
  - `POST /content/:id/review`
  - `POST /exports`
  - `GET /audit-logs`
  - Structured validation, auth, permission and error responses
- Root `test:data-api` script.

## Updated

- Root version is now `2.0.0`.
- Auth service can now use external User and Session repositories.
- Root `npm test` now runs data and API foundation tests.
- Repository verifier now requires the data/API packages and v2.0.0 release notes.
- README, Start Here, Master Index, Project Status, Final Review and Changelog now describe the data/API foundation release.
