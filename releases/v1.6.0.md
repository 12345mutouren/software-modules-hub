# v1.6.0 Release Notes

Date: 2026-06-04

## Summary

`v1.6.0` adds a Build Planner to the docs site.

The release gives project builders an execution planning surface that combines software type, current stage and team size into a practical build route.

## Added

- `planner.html` docs-site page.
- Interactive planner controls for software type, current stage and team size.
- Live focus, delivery window and risk summary.
- Six software directions: SaaS subscription, admin dashboard, ecommerce, content community, AI knowledge base and enterprise internal tool.
- Four-stage roadmap: Map, Prototype, Launch and Production.
- Links from the planner to Project Starter, Maturity Scorecard, kickoff templates, security review, production templates and deployment materials.

## Updated

- Home page now includes a Build Planner entry.
- Start Here, Explore and Master Index now route project builders to the planner.
- Docs-site navigation now includes Build Planner.
- Docs-site tests now verify the generated planner page.
- Root version is now `1.6.0`.
- README, Project Status, Final Review, Changelog and Master Index now reflect the build planner release.
