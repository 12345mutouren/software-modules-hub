# v1.4.0 Release Notes

Date: 2026-06-04

## Summary

`v1.4.0` turns the productized docs site into a clearer project launch surface.

The release adds a Project Starter page that connects each software type to a generator command, blueprint, runnable reference, generated package checklist and first-release gates.

## Added

- `project-starter.html` docs-site page.
- Interactive starter selector for six software types.
- Starter command display for `starter-generator/create-starter.mjs`.
- Starter profile cards for SaaS, admin dashboard, ecommerce, content community, AI knowledge base and enterprise internal tools.
- Generated package overview for product brief, module selection, permission matrix, data model, API contract, security review, test plan and launch plan.
- First-release gate cards for product clarity, data boundaries, API verification and launch recovery.

## Updated

- Home page now routes project builders to the Project Starter.
- Start Here and Explore now include Project Starter as the direct build entry.
- Docs-site navigation now includes Project Starter.
- Docs-site tests now verify the generated Project Starter page.
- Root version is now `1.4.0`.
- README, Project Status, Final Review, Changelog and Master Index now reflect the project starter experience.
