# v1.7.0 Release Notes

Date: 2026-06-14

## Summary

`v1.7.0` adds a Stack Composer to the docs site.

The release gives project builders a practical way to combine software type, authentication strategy, data layer, deployment style and optional capabilities into a starter technical architecture.

## Added

- `stack-composer.html` docs-site page.
- Interactive controls for software type, auth strategy, data layer, deployment style and optional capabilities.
- Live recommended stack output.
- Live project focus and starter-generator command.
- Risk review panel for the selected stack.
- Reference repository chips that point back to the GitHub repository browser.
- Release gates tailored to the selected software type.

## Updated

- Home page now includes a Stack Composer entry.
- Start Here, Explore and Master Index now route project builders to the composer.
- Docs-site navigation now includes Stack Composer.
- Docs-site tests now verify the generated composer page.
- Root version is now `1.7.0`.
- README, Project Status, Final Review, Changelog and Master Index now reflect the stack composer release.
