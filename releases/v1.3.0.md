# v1.3.0 Release Notes

Date: 2026-06-04

## Summary

`v1.3.0` turns the docs site into a productized static knowledge site.

The release adds a visual homepage, goal-based navigation, template selection, GitHub repository browsing, GSAP motion, a Three.js module network and a live GitHub Pages deployment workflow.

## Added

- Productized docs-site homepage.
- Goal-based `Start Here` and `Explore` pages.
- Template selector page for SaaS, ecommerce, AI knowledge base, admin, content and enterprise directions.
- GitHub repository browser with search, module filter and type filter.
- Local docs-site CSS and JavaScript assets.
- GSAP reveal and filter motion.
- Three.js homepage module network.
- Actual `.github/workflows/docs-site.yml` deployment workflow.
- Root `build:docs-site` command.

## Updated

- Docs-site tests now verify generated product pages, assets and repository browser content.
- Repository verifier now requires docs-site assets and the deployment workflow.
- Quality and deployment documentation now describe the productized docs-site workflow.
