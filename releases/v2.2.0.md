# v2.2.0 - Professional Backend Foundation

Date: 2026-06-14

## Summary

This release upgrades the code foundation from a runnable demo backend into a more professional backend structure.

The repository now includes a dedicated database foundation package with migrations, table registration, unique indexes, transaction rollback and a durable JSON file adapter. The API layer also has service objects so routes are no longer the only place business logic lives.

## Added

- `packages/database` package.
- Migration ledger and foundation table registry.
- Unique lookup indexes for users, sessions and roles.
- Memory database adapter for fast tests.
- JSON file database adapter for local durable data.
- Generic database repository factory.
- Service layer for content, export and audit workflows.
- Durable database tests across database, data, API and web admin layers.
- `DATA_FILE` support in `apps/web-admin-app`.
- Root `test:database` script.

## Updated

- Root version is now `2.2.0`.
- `packages/data` can run on database adapters.
- `packages/api` accepts a database adapter and keeps business logic in services.
- Role seeding is idempotent for persistent database restarts.
- Web admin app can persist demo data when launched with `DATA_FILE=/path/to/app.json`.
- README, Start Here, Master Index, Project Status and Final Review now describe the database foundation.
- Repository verifier now requires the database package and this release note.

## Verification

```bash
npm run test:database
npm run test:data-api
npm run test:web-admin
npm test
```

## Why It Matters

Professional backend code is not just routes and arrays. It needs stable storage boundaries, migrations, service logic, repeatable tests and restart-safe behavior.

This release adds that missing layer while keeping the repository dependency-light and easy to inspect.
