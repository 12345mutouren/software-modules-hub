# Security Release Runbook

安全相关发布包括：认证、权限、支付、密钥、数据访问、隐私和审计变化。

## Before Release

- [ ] 明确涉及哪些安全边界。
- [ ] 检查所有接口权限。
- [ ] 检查数据归属和租户隔离。
- [ ] 检查 Session/JWT/Cookie 行为。
- [ ] 检查 CSRF、XSS、SQL 注入风险。
- [ ] 检查限流和验证码策略。
- [ ] 检查审计日志是否覆盖敏感操作。
- [ ] 检查密钥是否没有进入 Git。

## Testing

- [ ] 管理员可以访问授权资源。
- [ ] 普通用户不能访问管理员资源。
- [ ] 用户不能访问别人的数据。
- [ ] 只读用户不能写入。
- [ ] 已登出 Session 不能继续访问。
- [ ] 过期或错误 Token 被拒绝。
- [ ] 支付 webhook 签名校验失败时被拒绝。

## Release

- [ ] 小流量或灰度发布。
- [ ] 观察认证失败率。
- [ ] 观察 401/403 错误变化。
- [ ] 观察登录、注册、支付和核心业务指标。
- [ ] 保留回滚方案。

## After Release

- [ ] 更新安全文档。
- [ ] 更新管理员操作手册。
- [ ] 更新权限矩阵。
- [ ] 记录审计结论。
