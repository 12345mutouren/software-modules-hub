# Link Audit

## Automated Command

```bash
npm run check:links
```

## Manual Checks

- Root README links.
- Master Index links.
- Phase checklist and audit links.
- Showcase tour links.
- Example and template links.
- Security and operations links.

## Rules

- Local Markdown links must point to existing files or directories.
- External URLs should be reviewed manually for relevance.
- Anchor-only links are allowed.
- Code blocks are not treated as documentation links.
