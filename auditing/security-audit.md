# Security Audit

## Scope

- Example code.
- Security guidance.
- Deployment guidance.
- GitHub workflow.
- Generated starter content.

## Checks

| Area | Check |
| --- | --- |
| Secrets | No real secrets committed |
| Auth | Passwords are hashed in examples |
| Permissions | Scoped access is tested |
| CSRF/XSS | Demo controls exist where relevant |
| Deployment | Production docs do not encourage unsafe defaults |
| Privacy | Export and deletion flows are documented |

## Escalation

Critical security issues should block release until corrected.
