# GitHub Repository Audit

## Scope

Review representative GitHub repositories listed in the catalog and module docs.

## Checks

| Check | Why |
| --- | --- |
| Repository still exists | Prevent dead references |
| Project is active enough for its category | Avoid misleading recommendations |
| License is visible | Helps users understand reuse |
| README explains usage | Useful for learners |
| Category is correct | Prevent framework/template/platform confusion |
| Security posture is acceptable for learning | Avoid unsafe defaults |

## Evidence

Record checked date, repository URL, category and decision.
