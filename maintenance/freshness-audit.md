# Freshness Audit

## Automated Command

```bash
npm run audit:freshness
```

## What It Checks

- Maintenance plans exist.
- Catalog source exists.
- Real project case study directory exists.
- Release cadence exists.
- Changelog exists.

## Manual Follow-Up

The command does not browse the internet. For current repository activity, maintainers should manually review linked GitHub projects or run a dedicated online audit.
