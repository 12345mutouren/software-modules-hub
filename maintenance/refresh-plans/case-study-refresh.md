# Case Study Refresh

## Cadence

- Quarterly for all real project case studies.
- Earlier when a project changes architecture significantly.

## Checks

| Check | Why |
| --- | --- |
| Project still active | Avoid stale learning material |
| Source entry points still valid | Keep readers oriented |
| Module map still accurate | Avoid architecture drift |
| Risks and caveats still true | Keep warnings useful |
| Suggested exercise still relevant | Keep learning path practical |

## Output

- Update case study README.
- Update Master Index only when entries change.
- Add audit note if a project is removed or replaced.
