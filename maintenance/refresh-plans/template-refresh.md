# Template Refresh

## Cadence

- After every new runnable example.
- After every new production template.
- Before minor releases.

## Checks

| Template Type | Check |
| --- | --- |
| Complete app templates | Still map to all 10 modules |
| Starter generator | Generated docs and code scaffold still pass tests |
| Runnable templates | Contract tests still pass |
| Production templates | Stack assumptions still match current guidance |
| Security templates | Security guidance still aligns with current risk model |

## Output

- Update template docs.
- Update verifier coverage if new files become required.
- Add tests for new runnable behavior.
