# GitHub Repository Index Refresh

## Cadence

- Monthly for high-value repositories.
- Quarterly for the full catalog.
- Immediately when a linked project is archived, renamed or removed.

## Checks

| Check | Decision |
| --- | --- |
| Repository still exists | Keep, update or remove |
| Category still correct | Keep or reclassify |
| README still useful | Keep or replace |
| License visible | Keep with note or replace |
| Activity level acceptable for learning purpose | Keep, mark stale or replace |

## Output

- Update `catalog/github-repositories.md`.
- Update module docs when category changes.
- Record major changes in `CHANGELOG.md`.
