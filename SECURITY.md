# Security Policy

## Supported Scope

This repository is a learning and planning hub. It contains documentation, examples, templates, scripts and testable demos.

## Reporting A Security Issue

If you find a security issue in the examples, scripts or guidance:

1. Do not publish exploit details publicly first.
2. Open a private report if repository settings support it, or contact the maintainer through the repository owner.
3. Include affected file, reproduction steps and expected impact.

## What Counts

- Vulnerable example code.
- Unsafe security guidance.
- Leaked secret-like values.
- Broken access-control examples.
- Misleading production deployment guidance.

## What Does Not Count

- Missing production integrations in intentionally small demos.
- External project vulnerabilities in linked third-party repositories.
- General requests for architecture advice without a concrete security issue.
