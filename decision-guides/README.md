# Decision Guides

第六阶段决策指南目录。

目标：当你有一个软件想法时，帮助你快速判断应该选择哪类模板、哪些模块、哪些技术和哪些开源仓库。

## Guides

| Guide | 解决的问题 |
| --- | --- |
| [software-type-selector.md](software-type-selector.md) | 你的软件更像 SaaS、后台、电商、社区、AI 知识库还是内部工具 |
| [auth-decision-tree.md](auth-decision-tree.md) | 登录注册和权限系统怎么选 |
| [database-decision-tree.md](database-decision-tree.md) | PostgreSQL、MongoDB、Redis、搜索、对象存储、向量库怎么选 |
| [frontend-backend-decision-tree.md](frontend-backend-decision-tree.md) | 前端、后端和 API 风格怎么选 |
| [deployment-decision-tree.md](deployment-decision-tree.md) | Vercel、Docker、Kubernetes、Serverless、自托管怎么选 |
| [avoid-overengineering.md](avoid-overengineering.md) | 什么情况下不要上复杂架构 |

## 使用方式

1. 先用软件类型选择器确定方向。
2. 再分别选择账号、数据库、前后端和部署方案。
3. 最后用避免过度工程指南砍掉不必要的复杂度。
4. 进入 [project-kickoff](../project-kickoff/README.md) 生成项目启动包。
