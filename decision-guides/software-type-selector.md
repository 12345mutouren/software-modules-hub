# Software Type Selector

先判断软件类型，再选模块和技术。不要从“我想用什么框架”开始。

## Quick Decision Table

| 你的目标 | 优先选择 |
| --- | --- |
| 做一个收费在线工具 | SaaS 订阅系统 |
| 管理用户、内容、订单或配置 | 管理后台 |
| 卖商品、课程、服务或数字产品 | 电商系统 |
| 做帖子、评论、关注、审核 | 内容社区 |
| 做文档问答、企业知识库、AI 搜索 | AI 知识库 |
| 做公司内部审批、工单、报表 | 企业内部工具 |

## Questions

### 1. 用户是谁？

| 答案 | 倾向 |
| --- | --- |
| 普通互联网用户 | SaaS、电商、内容社区 |
| 企业客户 | SaaS、AI 知识库、企业内部工具 |
| 内部员工 | 管理后台、企业内部工具 |
| 管理员/运营/客服 | 管理后台 |

### 2. 主要业务对象是什么？

| 业务对象 | 倾向 |
| --- | --- |
| 订阅、用量、团队 | SaaS |
| 用户、内容、订单、配置 | 管理后台 |
| 商品、库存、订单、支付 | 电商 |
| 帖子、评论、关注、举报 | 内容社区 |
| 文档、分块、向量、问答 | AI 知识库 |
| 工单、审批、部门、附件 | 企业内部工具 |

### 3. 收费方式是什么？

| 收费方式 | 倾向 |
| --- | --- |
| 订阅 | SaaS |
| 一次性购买 | 电商 |
| 企业合同 | SaaS、AI 知识库、企业内部工具 |
| 不收费但需要运营 | 内容社区、管理后台 |

## Default Recommendation

如果你不确定，先选：

```text
SaaS 订阅系统 + 管理后台
```

原因：大多数真实软件最后都会需要账号、数据库、后台、权限、日志、部署、测试和文档。SaaS 模板能覆盖这些基础能力，管理后台能补运营和管理。
