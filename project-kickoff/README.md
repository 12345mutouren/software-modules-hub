# Project Kickoff

第六阶段项目启动包目录。

目标：把一个软件想法变成可以讨论、开发、测试和上线的项目资料。

## Templates

| Template | 用途 |
| --- | --- |
| [product-brief.md](templates/product-brief.md) | 产品目标、用户、核心流程 |
| [module-selection.md](templates/module-selection.md) | 10 大模块选型 |
| [architecture-decision-record.md](templates/architecture-decision-record.md) | 架构决策记录 ADR |
| [permission-matrix.md](templates/permission-matrix.md) | 角色和权限矩阵 |
| [data-model.md](templates/data-model.md) | 核心数据模型 |

| [test-plan.md](templates/test-plan.md) | 测试计划 |
| [launch-plan.md](templates/launch-plan.md) | 发布计划 |

## Recommended Flow

1. 写产品简报。
2. 做模块选择。
3. 写 2-5 条关键 ADR。
4. 画权限矩阵。
5. 草拟数据模型和 API。
6. 做安全审查和测试计划。
7. 写发布计划和风险登记。
