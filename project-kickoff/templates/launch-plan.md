- [ ] Tests pass.

- [ ] Rollback plan exists.
- [ ] User/admin docs ready.

## Launch Steps

1. Deploy to staging.
2. Run smoke tests.
3. Deploy to production.
4. Verify health check.
5. Verify critical flows.
6. Monitor metrics.
